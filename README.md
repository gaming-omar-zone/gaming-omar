## شنو تصلح في v2 (دمج على نسخة GitHub)

الـ ZIP اللي كان عند عمر كان نسخة قديمة (الأدمن فيها كان نسخة من `app.js`)،
أما GitHub فكان أحدث — فيه أدمن حقيقي وروابط التواصل الحقيقية.
هاد النسخة **دمجت الإصلاحات على نسخة GitHub**، وما مسحاتش الجديد ديالها.

### أخطاء تصلحات
1. **تبويب البلاغات كان كيكراش** — `admin.html` كيعيط لـ `loadAdminReports()` وهي ما كانتش موجودة في `admin.js`. دابا موجودة: عرض البلاغات + "تم الإصلاح" + حذف + عداد البلاغات في الإحصائيات.
2. **فورم "اتصل بنا" كان وهمي** — كيعرض "تم الاستلام" بلا ما يحفظ والو. دابا كيحفظ في جدول `contact_messages`، وكاين تبويب جديد "رسائل الزوار" في الأدمن.
3. **حفظ المود كان كيضيع حقول** — فورم الأدمن فيه أونلاين/أوفلاين، الرام، المعالج، يوتيوب، Drive/Mega، ولكن `handleSaveMod` كان كيحفظ غير 8 حقول. دابا كيحفظهم كاملين، والتعديل كيعمرهم كاملين، وكيحافظ على الملف القديم إلا ما رفعتيش ملف جديد.
4. **جدول الأدمن كان مخربق** — الهيدر فيه 7 أعمدة والصفوف فيها 6 (عمود التقييم ناقص). دابا 7/7: صورة، عنوان + منشور/مسودة، تصنيف، حجم، تقييم، تحميلات، إجراءات (تعديل / نشر-إخفاء / حذف).
5. **`switchAdminTab` كان كيستعمل `event` العام** — غير موثوق. دابا كيلقى الزر بـ selector، وكل تبويب كيعمر البيانات ديالو ملي تفتحو.
6. **XSS في التعليقات والبطاقات** — اسم المعلق ونص التعليق وعناوين الألعاب كانو كيتحطو بـ `innerHTML` بلا حماية. دابا كلشي escaped، والتعليقات كتبنى بـ `textContent`.
7. **ستايلات ناقصة** — `secure-tag` و `btn-danger` و badges ما كان عندهم حتى ستايل. تزادو.

### تطويرات
- ترتيب: الأحدث / الأكثر تحميلاً / الأعلى تقييماً + عدد النتائج
- التقييم: مرة وحدة لكل لعبة من نفس المتصفح، والمعدل كيتحدث من قاعدة البيانات
- إلا فشل جلب الألعاب: صندوق خطأ + زر "إعادة المحاولة" بدل spinner معلق
- بحث debounced، صور fallback، زر Escape كيسد المودال، بحث داخل لوحة الأدمن
- `schema.sql` جديد في الريبو (ما كانش فيه): الأعمدة الناقصة + جداول `comments` / `broken_links` / `contact_messages` / `game_requests` + دالة `add_mod_rating()` + RLS
- SEO: favicon 🎮، `og:image`، `twitter:card`، `theme-color`
- قسم "الرائج الآن": أعلى 6 حسب التحميلات (مخفي حتى تكون ألعاب منشورة)
- صفحة "اطلب لعبة": الزوار يطلبو لعبة، والأدمن يقبل/يرفض/يعلن تمت الإضافة من تبويب "طلبات الألعاب"
- ديزاين زجاجي (بلور آيفون) + طبقة نيون عصرية

## كيفاش تطبق الإصلاح

### 1. قاعدة البيانات — Supabase
1. Supabase > SQL Editor > New query
2. الصق محتوى `schema.sql` كامل وشغلو (Run). آمن إلا عاودتيه.

### 2. حساب الأدمن
1. Supabase > Authentication > Users > Add user
2. Table Editor > `profiles` > زيد سطر: `id` = UUID ديال المستخدم، `email`، `role` = `admin`
3. دخل `admin.html` بهاد الإيميل وكلمة السر.

### 3. النشر — GitHub Pages
Settings > Pages > Source: Deploy from a branch > Branch: `main` > Folder: `/`
الموقع: https://gaming-omar-zone.github.io/gaming-omar/
