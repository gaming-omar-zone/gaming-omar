# Gaming Omar — v2 (مصلح ومطور)

موقع ألعاب أندرويد + مودات GTA SA، مبني بـ HTML/CSS/JS + Supabase.

## شنو تصلح في v2

### أخطاء حرجة
1. **لوحة الأدمن كانت مهرسة كاملة** — `admin.js` كان نسخة طبق الأصل من `app.js`، فحتى دالة من دوال الأدمن ما كانتش موجودة. دابا `admin.js` جديد كامل: دخول، إضافة/تعديل/حذف لعبة، نشر/إخفاء، رفع صورة وملف APK/ZIP لـ Supabase Storage، إدارة التصنيفات، البلاغات، رسائل الزوار، إعدادات البانر.
2. **قاعدة البيانات ناقصة** — `schema.sql` v2 زاد:
   - أعمدة ناقصة في `mods`: `youtube_url`, `is_online`, `ram_req`, `gpu_compat`, `link_drive`, `link_mega`, `rating_avg`, `rating_count`
   - جداول جديدة: `comments`, `broken_links`, `contact_messages`
   - دالة جديدة: `add_mod_rating()` (التقييم كان كيفشل حيت الدالة ما كانتش)
   - RLS policies للجداول الجديدة
3. **فورم "اتصل بنا" كان وهمي** — كيعرض "تم الاستلام" بلا ما يحفظ والو. دابا كيحفظ فعلاً في `contact_messages`، وكاين تبويب "رسائل الزوار" في الأدمن باش تقراهم.
4. **عداد التحميل** — كان كيزيد التنزيلات بلا ما يتحمل شي واحد، والـ timer كان كيبقى خدام إلا سديتي النافذة. دابا: العداد كيزيد **مرة وحدة ملي تكليكي فعلاً على رابط تحميل**، والـ timer كيتلغى ملي تسد المودال.
5. **البحث كان كيكراش** إلا كان `short_desc` فارغ، والتعليقات/العناوين كانو كيتحطو بـ `innerHTML` بلا حماية (XSS). دابا كلشي escaped + null-safe.
6. **ستايلات ناقصة** — `btn-download-big` و `secure-tag` ما كان عندهم حتى ستايل. تزادو + `btn-danger` + badges منشور/مسودة.

### تطويرات
- ترتيب: الأحدث / الأكثر تحميلاً / الأعلى تقييماً + عدد النتائج
- التقييم: مرة وحدة لكل لعبة من نفس المتصفح، والمعدل كيتحدث من قاعدة البيانات
- إلا فشل جلب الألعاب: كيبان صندوق خطأ + زر "إعادة المحاولة" بدل spinner معلق
- بحث debounced (150ms)، صور fallback إلا كان رابط الصورة خربان، زر Escape كيسد المودال
- بحث داخل لوحة الأدمن، checkbox "نشر فوراً / مسودة"
- SEO: favicon 🎮، `og:image`، `twitter:card`، `theme-color`

## كيفاش تطبق الإصلاح (مهم)

### 1. قاعدة البيانات — Supabase
1. دخل Supabase > SQL Editor > New query
2. الصق محتوى `schema.sql` كامل وشغلو (Run). آمن إلا عاودتيه، حيت كامل `IF NOT EXISTS`.
3. إلا كان عندك ألعاب قدام، الأعمدة الجديدة غادي يتزادو بـ `ALTER TABLE` اللي في الملف.

### 2. حساب الأدمن
1. Supabase > Authentication > Users > Add user (الإيميل + كلمة السر ديالك)
2. Supabase > Table Editor > `profiles` > زيد سطر: `id` = نفس UUID ديال المستخدم، `email` = إيميلك، `role` = `admin`
3. دخل `admin.html` بهاد الإيميل وكلمة السر.

### 3. النشر على GitHub
المشروع static (بلا build)، يعني:
- دفع الملفات للريبو ديالك في GitHub
- GitHub repo > Settings > Pages > Source: Deploy from a branch > Branch: `main` > Folder: `/` (إلا كان الريبو فيه غير هاد المشروع) أو `/GamingOmar_Project`
- الموقع غادي يولي على `https://<username>.github.io/<repo>/`

### 4. باقي عليك تبدل (روابطك أنت)
- زر تيليجرام في `index.html`: الرابط دابا `https://t.me/` فارغ — بدل `t.me/` بـ `t.me/username-dialek`
- روابط يوتيوب / تيليجرام / فيسبوك في الفوتر ديال `index.html` — دابا `#`، بدلهم بروابطك الحقيقية
